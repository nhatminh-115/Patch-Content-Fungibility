# Final Paper Claims Table

**Repository:** [Patch-Content-Fungibility](https://github.com/nhatminh-115/Patch-Content-Fungibility)  
**Date:** October 7, 2026  
**Status:** Authoritative Post-Audit Release  

This table catalogs all core claims intended for the manuscript, classified according to empirical strength:
- **STRONG:** Statistically verified with tight confidence intervals, cross-architecture confirmation, and rigorous matched controls. (Main Text)
- **SUPPORTED:** Confirmed by multiple experiments with clear boundary conditions identified. (Main Text / Supplement)
- **EXPLORATORY:** Phenomenon observed and reproducible, but architectural variation or mechanism warrants further study. (Discussion / Supplement)
- **NEGATIVE RESULT:** Hypothesized mechanism or formulation disproven or bounded by empirical data. (Explicitly reported in Main Text / Supplement to prevent community pitfalls)
