## Classification Rules

- “Strong” and “supported” apply only to the listed model, protocol, metric, and sample unit.
- An operator-space quantity never substitutes for Top-1 or measured model-call performance.
- Real-final accuracy/throughput evidence comes only from `outputs/fungibility_real_final/`.
- `outputs/fungibility_final_consolidation/` is not a source for proxy accuracy, latency, or frontier claims; its audited operator-space results are cited only with explicit labeling.
- The strict confirmatory evaluation is N=1,000 per architecture. Attention and functional-geometry audits are N=100 images; multi-block operator validation is N=100 perturbations.
