# Frozen protocol: functional set-aware token merging

**Frozen before new model evaluation.** This branch starts from PR #5 commit `160f6e7`. Phases run in order A→B→C→D; a failed gate stops dependent work. Oracle logits/effects are offline only. No seed-9201 held-out image, manuscript, supplement, or historical output may be used or edited.

## Motivation and cohorts

PR #5 found independent-oracle 16-merge headroom against cosine in both models; conditional greedy improved over independent by `2.781e-5` (19.8%) on DeiT-Small's 64 previously used stability images. The old student's completed-set deficit was 91%/86% explained by summed one-action damage, so any practical method must first select individually safer actions. Shared destinations exhibited non-additive effects. One model seed each: frozen DeiT-Small Block 8 and ViT-B/16 AugReg Block 7, FP32 pretrained suffix and classifier.

Phase A begins on the same 64 `stability` seed-9101 calibration images, previously used to choose the old checkpoint; the 128 disjoint `pilot` calibration images replicate decisive contrasts. These are exploratory research cohorts already used in PRs #4–5, not new confirmation. If C is entered, split the prior 808 `train` calibration images by a new fixed seed `76131` into 640 training and 168 validation images, preserving class/image disjointness. Both subgroups were exposed to prior student training; this is a new split for the proposed method, not independent external data. The 64 and 128 cohorts are reserved for post-training diagnostic evaluation only. All image IDs and partitions are recorded.

Use the PR #5 teacher-label 32-edge pool at original 196-patch states with identical candidate access for all methods. Source indices are unique, even, disjoint from odd destinations; multiple sources may share a destination. Apply every selected set to the original state. Preserve CLS, exact token count, weighted carrier averages, multiplicity conservation, multiplicity attention bias, and full-model no-merge parity below `5e-4`. Candidate and selected-set suffix calls use cached equal-length batches. Image-level paired 95% percentile intervals use 2,000 resamples, seed `76112`.

## A: offline functional approximation

For each image and candidate a, cache clean logits, current logits, and actual single-action logits. Let `e=center(z(s)-z_clean)`, `delta_a=center(z(s+a)-z(s))`, and denominator `||center(z_clean)||²+1e-8`. Define additive predicted set D as `||e+Σdelta_a||²/denominator`. **Additive greedy** chooses, at each step, the feasible candidate minimizing this prediction for the enlarged set; it never queries a joint teacher outcome to choose. Exact conditional greedy is the PR #5 set oracle, included solely as an offline upper control. Independent oracle ranks actual one-action D. Cosine ranks similarity. Select 16 where feasible and evaluate every chosen prefix k=1,2,4,8,16 with actual suffix forwards.

Destination-load correction is pre-specified: `lambda=median(single-action D across the 32 actions)`, multiplied by the number of already selected sources sharing a candidate destination. Apply it separately to independent single-action selection and additive greedy. Also compute maximum no-shared-destination matching cardinality within the fixed pool, and run hard distinct-destination additive greedy to that cardinality. Compare its D only with unrestricted controls at the **same cardinality**; never credit fewer merges. No pool expansion or penalty tuning on outcomes is allowed in this phase.

Primary estimand: completed 16-merge mean independent-oracle D minus additive-greedy D. Also compare penalty variants, cosine, and conditional oracle; report actual D, paired absolute differences/intervals, relative differences, fraction of independent→conditional gain recovered, conditional regret, selection overlap, destination collisions, summed individual D, additive cross term, actual-minus-additive residual, and scorer runtime. Explain both positive and negative interaction cases. The correction's effect is a separate ablation.

**Gate A GO:** on 64 stability images, the best *pre-specified functional variant* (additive greedy or additive+load correction) must beat the better of independent and independent+load correction by at least `1e-5` absolute D, recover at least 50% of the independent→conditional advantage on DeiT-Small, and have a positive paired lower 95% bound; the selected variant must have the same improvement sign on the 128-image pilot cohort. Both functional variants and both cost-only controls are always reported, so this choice is transparent. If only destination penalization improves outcomes, stop functional projection/training and recommend a simpler penalty study. ViT-B is evaluated with its absolute scale reported but is not required to pass the DeiT-derived gate. A fails if no functional variant meets the criterion.

## B: compress action-induced output effects

Enter only after A GO. Project each centered `delta_a` and `e` with a fixed Gaussian matrix of entries `N(0,1/d)` for dimensions d=16,32,64,128, independently seeded by `76151+d+architecture_offset`; no basis is fit on validation outcomes. Compare projected pair inner products (Spearman over admissible pairs), additive set-damage ranks (Spearman over the 32 one-step enlarged sets at each greedy step), actual selected 16-merge D, and CPU/GPU scoring time against full 1,000-logit additive greedy. Actual suffix calls score selected sets only. Report parameter/storage/operation counts and projection construction time separately from greedy scoring. Replicate a passing dimension on 128 pilot images.

**Gate B GO:** some d≤64 must retain ≥80% of the Phase-A functional improvement over the better cost-only control on 64 images, have a positive paired mean improvement over that control with positive bootstrap lower bound, and preserve the sign on 128 images. Median per-image admissible-pair inner-product Spearman must be ≥0.70 and measured greedy scoring must be ≤5 ms/image on the available device, excluding offline teacher-vector generation. If not, stop before learning. Dimensions 128 and full-logit are diagnostic ceilings, not license to enlarge a deployed method.

## C: minimal practical student

Enter only after A and B GO. No clean logits, true effect vectors, suffix outputs, or class label may enter inference. Train a ridge/linear fixed-feature predictor first using the 10 PR #4 pair features, source/destination activation summaries, and patch count; targets are log-scaled individual D and projected effect vectors from permitted 640 training images. Standardization and regularization (`alpha∈{0.1,1,10}`) use training only; choose alpha by the 168-image validation cohort's **actual selected-16 set D**. If linear capacity fails the gate, stop without training a larger neural scorer. Loss/fit must emphasize all selected 16 actions and high-damage mistakes; retain raw score and effect components for diagnosis. Controls: cosine, old frozen pair student, old fixed-feature regression, old learned embedding without counterfactual labels, and independent/conditional teachers as nondeployable references. Use identical 32-edge pools and candidate constraints, and compare individual-only, destination penalty, effect alignment, and both corrections.

**Gate C GO:** on the untouched-for-this-method 128-image pilot cohort, the proposed student must beat cosine at 16 merges by ≥`1e-5` absolute and ≥10% relative mean D, with positive paired lower 95% bound, and reduce summed selected one-action D. It must also have the same sign on the 64-image stability cohort. Report regret against both oracles. If it fails, stop before complete rollouts. These reused cohorts limit claims to exploratory algorithm selection.

## D: complete compression and practical viability

Enter only after C GO. On 64 calibration images compare exact retained counts 98 and 49, all same-schedule controls, existing ToMe, and Hybrid Group Mean. Report full-model D, Top-1, clean-prediction preservation, prefix trajectory, matched teacher action regret at ToMe/self states, and paired intervals. Distinguish individual cost, output alignment, non-additive response, and state-policy shift. No silent on-policy retraining.

**Gate D GO:** at both 98 and 49 patches in both architectures, the new student beats the strongest comparable same-schedule control in mean D with positive paired lower 95% bound and loses no more than one percentage point of Top-1; also state its position versus ToMe and Hybrid Group Mean. If not, stop and report the divergence point. Only after D GO may batched end-to-end latency, throughput, peak memory, and accuracy–throughput Pareto measurements be claimed. No theoretical FLOP number counts as demonstrated acceleration.

## Compute, tests, and final decision

Run a two-image/model correctness/runtime smoke test before each entered full phase. Record actual wall time, teacher suffix time/count, practical scoring time, and peak allocated GPU memory. Target ≤4 GPU-hours and ≤8 GiB peak; if projection or training would exceed this, stop with measured feasibility evidence. Tests must cover additive-vector arithmetic, source constraints, destination penalties, equal-token comparisons, multi-action suffix equivalence, CLS/mass invariants, and absence of teacher information at deployed selection.

Final recommendation is exactly one of: **GO** only if D and practical throughput pass; **REVISE** if A/B find exploitable offline structure but C or D fails, with a specific bounded next experiment; **KILL** if A or B fails to show useful functional-vector structure. Never imply a learned score or projected output features are novel by themselves. Compare with ToMe, DTEM, PiToMe, and task-aware methods using primary papers, with the narrow experiment-specific distinction stated. Commit code, small aggregate/per-image outputs, manifests, tests, and report to a new PR stacked on PR #5; do not merge any PR.
