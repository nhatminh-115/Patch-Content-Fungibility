# G0 prior-art audit: signed Value-error merge selection

**Decision before model evaluation: GO to a bounded proxy-validity pilot, not a novelty claim.** The candidate distinction is a *training-free simultaneous ViT merge-set selector* that forms signed, head-resolved, frozen-attention Value replacement errors for each action and penalizes their summed vector. The identity by itself is elementary algebra; signed vector balancing is established in other attention-compression settings. A practical contribution would require measured downstream and runtime gains.

The compared object is precise: at a fixed intervened ViT state, for a merge `(i,j)` with source/destination multiplicities `(m_i,m_j)`, one query's frozen-attention Value aggregate changes by a signed term proportional to `(a_i m_j-a_j m_i)(v_i-v_j)/(m_i+m_j)`. We propose to use the *preceding block's* per-head CLS attention and Value tensors as an available but potentially invalid proxy for the next block, then select a source-disjoint set by its individual squared norms and the squared norm of its signed sum. It is neither a Jacobian nor an exact final-logit effect. The same idea applied to a different query or readout would define a different proxy.

| Primary work | Actual method or equation relevant to this audit | Precise overlap | Missing from that work relative to this proposal / important difference |
| --- | --- | --- | --- |
| [ToMe](https://arxiv.org/pdf/2210.09461) | Bipartite matching ranks normalized token-key cosine, merges by size-weighted mean, adds `log(size)` to attention. | Identical merge mechanics and proportional attention baseline. | No per-head signed Value replacement error or set-level vector cancellation score. |
| [MCTF, CVPR 2024](https://arxiv.org/html/2403.10030v3), [supplement](https://openaccess.thecvf.com/content/CVPR2024/supplemental/Lee_Multi-criteria_Token_Fusion_CVPR_2024_supplemental.pdf) | Pair attraction is a product of cosine, inverse attention informativeness `1/(a_i a_j)`, and inverse size `1/(s_i s_j)`; uses one-step-ahead attention because previous-block maps differ, then bidirectional matching and a consistency-trained variant. | Attention, size, and matching are direct controls; the **previous-block proxy warning is directly applicable**. | Attention enters as a scalar pair importance, not a signed per-head Value-error vector summed across chosen merges. Their one-step-ahead map is not free under this task's no-second-QKV constraint. |
| [DTEM, NeurIPS 2024](https://arxiv.org/html/2412.10569v1) | A learned decoupled embedding sets pair cosine for soft grouping/merging; differentiable relaxation trains it modularly or end-to-end. | Improves task-aware merge policy. | Requires learning; no specified analytic signed Value aggregate or fixed-attention error cancellation. A new learned score alone would duplicate the broad idea. |
| [ATM / Lossless Token Merging](https://arxiv.org/pdf/2505.15160) | Layer-specific cosine thresholds, size-distinctive matching; its per-merge error is a multiplicity-weighted *cosine distance* to the weighted mean, bounded by a size-weighted pair distance. | Same carrier/multiplicity issue and training-free efficiency target. | Unsigned representation-space error and adaptive count, not head-resolved signed Value error or joint cancellation. |
| [HAC, WACV 2026](https://openaccess.thecvf.com/content/WACV2026/papers/Ichikawa_Efficient_Vision_Transformers_via_Token_Merging_with_Head-wise_Attention_Correction_WACV_2026_paper.pdf), [supplement](https://openaccess.thecvf.com/content/WACV2026/supplemental/Ichikawa_Efficient_Vision_Transformers_WACV_2026_supplemental.pdf) | Adds head-specific corrections to merged-token attention scores, either calibrated diagonal expectation or learned `f_h(size)`; addresses Q/K self-attention distortion missed by proportional attention. | Head resolution and attention-distortion mechanism are close. | Corrects *post-merge QK scores* for a given ToMe match; does not rank action sets by signed Value replacement errors. Its mechanism identifies a likely missing term in our proxy. |
| [SAD-TM, CVPR 2026](https://openaccess.thecvf.com/content/CVPR2026/papers/Xie_Saliency-Driven_Token_Merging_for_Vision_Transformers_CVPR_2026_paper.pdf), [supplement](https://openaccess.thecvf.com/content/CVPR2026/supplemental/Xie_Saliency-Driven_Token_Merging_CVPR_2026_supplemental.pdf) | Combines an offline input-gradient saliency-outlier statistic with inference-time head-averaged class attention as a scalar token importance `alpha a_i + beta o_i`, then merges low-score tokens and defers early merging. | CLS attention is an important scalar baseline; documents cross-layer variation. | It uses gradients offline and scalar importance, with no signed Value-space set objective. |
| [AdaMerge](https://arxiv.org/pdf/2605.27465) | Feature-affinity centrality (column sum of a row-softmax token affinity) weights similarity; per-layer merge count adapts to redundancy statistics. | Training-free salience-weighted matching and adaptive schedule. | Its feature-affinity is not model attention or a signed Value error; no cross-action vector cancellation. |
| [Statistically Calibrated Scaling, ICML 2026](https://proceedings.mlr.press/v306/zhou26bj.html), [PDF](https://raw.githubusercontent.com/mlresearch/v306/main/assets/zhou26bj/zhou26bj.pdf) | Minimizes expected attention-output reconstruction risk over a *global* merged-Value scale and merged-logit correction; radial/angular decomposition yields `sqrt(r)` scaling. | Directly models attention-output Value error and exposes limitations of uncorrected proportional attention. | Optimizes correction parameters under statistical assumptions after clustering, not the assignment of discrete ViT merge actions using per-action signed errors. |
| [BalanceKV / Streaming Attention Approximation via Discrepancy Theory](https://arxiv.org/pdf/2502.07861) | Geometric correlated subset sampling balances signed vectors of keys/values to approximate streaming softmax attention for autoregressive KV-cache pruning. | **Closest conceptual overlap:** minimizing signed vector discrepancy to preserve an attention aggregate. It precludes claiming vector cancellation as a new principle. | Compresses an online KV cache by subset retention, with query-family guarantees; no multiplicity-weighted ViT token merges, preceding-block head-resolved merge-error identity, or the proposed discrete set objective. This is a bounded methodological distinction, not proof of priority. |
| [ApET, CVPR 2026](https://arxiv.org/abs/2602.19870) | Selects VLM visual tokens by norm of linear *feature reconstruction* residual against basis tokens, then similarity-merges removed tokens. | Approximation-error guided token compression. | The residual is unsigned token feature reconstruction; not an attention-weighted signed Value aggregate or jointly balanced merge-set error. |

Targeted searches also covered `signed value token merging`, `attention error compensation token merging`, and `joint error token merging`. They surfaced these close works but no exact same selection algorithm. Search absence is weak evidence; the primary-method distinctions above support only **G0 GO for testing**. If the prefix signal requires an extra full QKV, breaks optimized attention, or lacks downstream predictive power, the study must stop without a novelty or practical claim.

The previous PCF [counterfactual pilot](COUNTERFACTUAL_MERGE_PILOT_REPORT.md), [interaction diagnostic](COUNTERFACTUAL_MERGE_INTERACTION_REPORT.md), [functional-set study](FUNCTIONAL_SET_AWARE_MERGING_REPORT.md), [lightweight operator predictor](FUNGIBILITY_LIGHTWEIGHT_OPERATOR_PREDICTOR_REPORT.md), and [operator compression](FUNGIBILITY_OPERATOR_COMPRESSION_REPORT.md) motivate the test but are not prior publications. They show that one-action ranking is the larger deployed bottleneck, interaction-aware offline selection has modest additional headroom, and costly learned/operator routes have not delivered a practical crossover.
