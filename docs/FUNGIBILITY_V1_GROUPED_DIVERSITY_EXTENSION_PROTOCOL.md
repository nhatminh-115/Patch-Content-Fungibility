# Confirmatory Grouped-Diversity Extension Protocol

**Status:** Frozen before execution  
**Target:** Extend the complete-replacement grouped-diversity experiment to ViT-B/16 AugReg and DINOv2 ViT-S/14.  
**Purpose:** Test whether increasing the number of distinct, calibration-distributed surrogate vectors across patch positions is associated with downstream functional preservation beyond DeiT-Tiny/Small.

## Frozen design

- **Models/checkpoints:** \`vit_base_patch16_224.augreg_in1k\` from timm and the official \`dinov2_vits14_lc\` linear-classifier model (\`layers=1\`) from \`facebookresearch/dinov2\`, using the same frozen model definitions and model-specific preprocessing in \`patch_fungibility/v1_models.py\`.
- **Data:** Reconstruct the exact stratified, disjoint ImageNet-1k validation splits from \`patch_fungibility/v0_6_dataset.py\` with calibration seed 9101 and evaluation seed 9201; compare the ordered \`global_index\` and label columns against the existing V0.6 split manifests before inference. Each split contains 1,000 images, one per class.
- **Calibration:** Recompute Block-8 patch activation mean and unbiased per-feature standard deviation from the calibration split, then require agreement with the archived V1 \`calibration_statistics.npz\` (\`mu_8\`, \`sigma_8\`) before using the archived values for interventions. Calibration images are not evaluation images.
- **Intervention:** Replace all spatial patches at the output of Block 8 (input to Block 9), while leaving the CLS slot unchanged. Downstream blocks, normalization, and the official classifier readout are unchanged. For each image, sample K independent vectors from the diagonal Gaussian with the archived calibration mean and standard deviation; assign patch position t (zero-indexed among spatial patches) to prototype \`t mod K\`. Thus K=1 is shared noise and K=N_patches is independent noise.
- **K and seeds:** ViT-B uses \`{1,2,4,8,16,32,64,196}\`; DINOv2 uses \`{1,2,4,8,16,32,64,256}\`. Five sampling seeds: \`26001, 26002, 26003, 26004, 26005\`. These seeds were selected for this extension before new inference.
- **Random-number lifecycle:** Follow the original grouped-diversity sampler in \`patch_fungibility/v0_8_interventions.py\`: a CPU \`torch.Generator\` is initialized once per model/K/seed condition, advances continuously across evaluation batches, and samples float32 standard-normal values of shape \`(batch, K, feature_dim)\` before scaling by the calibration standard deviation. This preserves independent draws across images and matches the original grouped protocol’s sampling distribution and grouping semantics.
- **Measurements:** Save per-image logits-derived true-class margin, prediction, and correctness; seed-level Top-1 accuracy and mean/median true-class margin; and across-seed means and sample SDs. DINOv2’s official readout uses normalized CLS concatenated with the mean normalized patch representation, so its true-class margin is reported even if Top-1 remains at floor; margin changes are not called accuracy recovery.
- **Paired comparisons:** For every pair of K values, first average each outcome over the five seeds separately for each of the same 1,000 evaluation images. Compare those 1,000 image-level paired averages using paired t and Wilcoxon signed-rank tests; report a paired 95% t interval for the mean difference. Apply Benjamini-Hochberg correction within each model/metric family (28 K-pairs per family). Images are the independent units; seeds and patch positions are never counted as additional images.
- **Shape and consistency checks:** Require exact split identity and zero overlap, frozen weights, exact Block-8 activation-statistic agreement, clean-path prediction/margin parity with archived V1 per-image results, unchanged labels/sample ordering, exactly K prototype assignments, and 1,000 raw rows per model/K/seed.
- **Endpoint validation:** Compare the new K=1 condition against archived V1 \`SHARED_GAUSSIAN\` and K=N_patches against archived \`INDEPENDENT_GAUSSIAN\`, using their five existing seeds and the same evaluation images. For Top-1 and mean margin, compute the difference between across-seed means and its combined standard error; compatibility requires absolute difference no greater than 2 combined SE. A failed check requires code/data diagnosis and must be disclosed; do not silently substitute or tune conditions.
- **Interpretation:** Report strict monotonicity from the ordered seed-mean series and show every K. Describe high-K flattening only from the observed increments, without imposing a post-hoc saturation threshold. Keep model-level differences visible.
- **Figure plan:** Figure 3(b) will show a common-scale accuracy small-multiple for all four architectures with seed SD and clean baselines. If DINOv2 accuracy remains near floor, Supplementary Figure S10 will show its true-class margin versus K on a separate, explicitly labeled scale.
- **No tuning:** Do not change the model, depth, replacement fraction, calibration cohort/statistics, K values, seeds, assignment rule, preprocessing, or primary metric after observing extension outcomes. Do not rerun or modify DeiT results.
